# Supabase Setup Guide for CSE PathFinder

This project uses a dual architecture:
- **Cloud Mode**: Connects to Supabase PostgreSQL database when `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are set.
- **Offline / Local Mode**: Uses Browser LocalStorage database automatically if Supabase is not configured yet. **No server connection errors will ever occur!**

---

## 1. Create a Free Supabase Project

1. Go to [https://supabase.com/](https://supabase.com/) and click **Start your project** (Sign in with GitHub).
2. Click **New Project** and name it `cse-pathfinder`.
3. Choose a password and region, then click **Create new project**.

---

## 2. Run SQL Schema Script

In your Supabase Dashboard, click on **SQL Editor** on the left menu, paste the following SQL query, and click **RUN**:

```sql
-- 1. Students Table
CREATE TABLE IF NOT EXISTS students (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    college TEXT NOT NULL,
    year TEXT NOT NULL,
    branch TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Quiz Results Table
CREATE TABLE IF NOT EXISTS quiz_results (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_email TEXT NOT NULL REFERENCES students(email) ON DELETE CASCADE,
    quiz_type TEXT NOT NULL,
    recommended_domain TEXT NOT NULL,
    confidence_score DOUBLE PRECISION,
    all_scores JSONB,
    timestamp TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. Student Progress Table
CREATE TABLE IF NOT EXISTS student_progress (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_email TEXT NOT NULL REFERENCES students(email) ON DELETE CASCADE,
    domain_id TEXT NOT NULL,
    semester_num INTEGER NOT NULL,
    course_title TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'Not Started',
    notes TEXT,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(student_email, domain_id, semester_num, course_title)
);
```

---

## 3. Get Project Credentials & Deploy to Vercel

1. In Supabase, go to **Project Settings** -> **API**.
2. Copy your **Project URL** and **`anon` `public` Key**.
3. Create a `.env` file inside `frontend-react/` (or add environment variables in **Vercel Project Settings**):

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

---

## 4. Deploy to Vercel (1-Click)

1. Go to [https://vercel.com/](https://vercel.com/) and sign in with GitHub.
2. Click **Add New...** -> **Project**.
3. Import `Career-Guidence-For-CSE-Students`.
4. Set **Root Directory** to `frontend-react`.
5. Under **Environment Variables**, add:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
6. Click **Deploy**!
